# 历史分支：交互、声音与连续语音

本说明记录 `feat/epaper-interaction-audio` 保留的早期源码能力，用于对照和迁移，不是当前产品版本的实机验收公告。当前双手机、USB HID 和共享授权流程见仓库首页指向的公开开发分支。原功能源码和提交历史均保留。

## 实体键与声音

- A 短按翻页、双击回首页、按住说话；B 短按回首页、双击静音并进入声音页、长按停止。声音页 A 加、B 减。
- 首页与停止快捷保留，停止处理不等待墨水屏刷新；全部按键松开后才能再次开始。
- ES8311 离线中文状态播报、音量/静音/试听和 NVS 保存保留；静音不关闭麦克风。
- 旧电源实现含约 3 秒关闭电池保持的逻辑，与项目后续 5 秒/30 秒语义不同。不要跨版本套用按键时长；以对应固件源码、硬件配置和实机验收为准。
- 可选外接输入默认关闭，使用 `sdkconfig.external-keys.defaults` 配置；接线需核对对应硬件，不能把不同板卡引脚混用。

## 语音与结果

语音页保留自动收音、停顿后提交、提示后继续听的交互；结束区域、首页和翻页可结束收音，10 秒无声或最多 12 轮后退出。保留聊天上下文、结果大字页和结果音频。此分支不据此宣称具备常驻唤醒词或最新手机兼容性。

语音上传可用 `X-Voice-Dialogue: 1` 在识别后建立异步对话任务；无该标记的旧客户端保持仅识别。设备令牌、`X-Voice-Session` 与递增的 `X-Voice-Sequence` 共同限定回合。

| 接口 | 旧协议用途 |
|---|---|
| `POST /dialogue/text` | 文本调试入口，检查会话与停止序号 |
| `POST /dialogue/poll` | 等待、一次性交付命令或结束；重复轮询不重发动作 |
| `POST /dialogue/result` | 返回本次真实执行结果；重复或过期 ACK 拒绝 |
| `POST /dialogue/audio` | 本回合 16kHz、单声道、PCM16LE 结果，最多 30 秒 |
| `POST /dialogue/screen` | 200×200、5000 字节的大字结果与停止区域 |
| `POST /stop` | 取消匹配会话及截至指定序号的任务，不声称撤回已送达的动作 |

模型、语音合成和识别适配器都由部署者在仓库外配置。认证失败、网络故障和真实操作结果分别处理，不包含维护者的服务器地址或配置文件。

## 旧执行代码的边界

原板端 ADB 命令协议仍保留在历史分支源码；它依赖目标手机手动开启对应调试端口并完成授权，不是免授权输入，也不能恢复普通未 root 手机重启后关闭的调试端口。该路径不作为当前生产控制入口。项目最新约定要求生产动作走板端 USB HID，并依据真实授权画面核验。

旧测试、模拟步骤、编译成功与真实手机验收分别记录，不能将历史模拟成功当作新版本已经通过。
