# 2026-10-21 控制板交互与声音验证

## 已实现

200×200 墨水屏主页提供按住说话、手动控制与右上角声音入口；所有页面底部固定首页/停止。声音页以20%调整板子扬声器音量，支持独立静音和试听，设置持久保存。内置中文准备就绪、识别成功/失败、停止和试听短句，可离线播放；尚未接入任意AI回答TTS。麦克风输入增益不随播报静音改变。

录音松手优先于长按分类；滑出原始区域或切页会取消，不会滑回自动重录。屏幕刷新不阻断停止。触摸确认开启手机控制仍要求当前画面和新按压，保持原有2秒确认边界。

升级App的扫描随路由暂停/恢复，蓝牙关闭时提供恢复入口，连接就绪前禁止推送，文件错误会清除旧选择。传输中系统返回与中断按钮统一处理；通知在END前订阅。板端修复服务UUID、广播筛选、ATT最大值、DATA/END写入顺序、断连后的旧命令和校验取消。切换启动槽开始后不可撤销，App明确提示。

## 软件验证

- `python3 tools/test_host.py`：11个C/C++主机测试程序通过，覆盖触摸、页环、录音接触策略、音量界限、OTA校验前取消、提交边界与重连世代。
- `python3 -m unittest discover -s tests -v`：37项通过，包括板端/App UUID一致性和音频资源边界。
- `cd app && dart analyze lib test`：无问题。
- `cd app && flutter test`：5项通过，包括关闭蓝牙时320×568、1.6倍字体的恢复界面，以及早到READY、取消后迟到通知、设备错误和MTU分片。
- ESP-IDF 5.5.2、USB-local、ESP32-S3固件编译通过；版本2026.10.21-ui-audio。板载设备配置与密钥均未提交。
