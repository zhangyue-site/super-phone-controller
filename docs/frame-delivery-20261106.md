# 新帧交付与恢复边界

版本 1.3.8（45）包含屏障时间门槛、新帧节流和心跳回执断网恢复修正。

仅屏障改变或授权替换推进真实 Image 时间门槛；同一屏障的正常响应不会反复推进。ImageReader 节流保留其有界队列中的图像，到绝对截止时间再获取最新帧，避免丢弃静态页面唯一的末帧。门槛前、重复及超过两秒的图像仍被拒绝。

诊断每十秒记录固定数值计数和状态布尔值，诊断页读取时补充当前快照。记录源回调、合格帧、上传结果、状态轮询、授权与锁屏状态，不记录屏幕文字、图像或凭据。CPU 锁维持共享工作；亮屏锁仅在已经唤醒且未锁定、有新鲜任务需求与有效授权时有界持有，空闲释放，不修改全局息屏设置或绕过锁屏。

心跳 ACK 传输失败可进入既有 STOP、释放旧会话、重新鉴权流程；不重放原数据包。点击、拖动、保存及 USB 模式切换的未知回执结果不获得该恢复例外。

实机已验证安装、新画面读取以及一次板端 Home 动作后的新帧核验。连续业务运行仍未完成验收：一次观察遇到 OCR 传输超时；后续任务发生时手机已锁屏，源帧计数停止，但共享服务和中转仍存活。USB 拔出后才发生共享销毁。不能将不同阶段的错误统一归因为没有开启共享，也不能把这些局部结果写成批量业务成功。

待补强项包括向服务端提供有时效的锁屏诊断，以及准确区分锁屏、授权撤销和原因未明的新帧超时。实验取样详见 frame-sampling-20261106.md。
