# 1.6.8固件源码同步说明

本次是源码协作候选，不发布、构建运行固件或操作设备。它从已验证私有1.6.8构建的已跟踪源码中提取通用实现，基于清理后的公开分支独立准备；没有导入旧Git历史或私有对象引用。

## 实际同步范围

公开基线缺少26个1.6.8固件文件，23个既有文件存在实现差异。同步包括BLE08本地签名执行、USB实体键盘op13/14、Android双槽触摸描述符、HTTPS键盘处理、默认禁用ADB、OTA取消/代次/断点续传/传输预算/启动健康保护、电源策略及68张产品化静态页面。相应生成器和主机测试一同同步。

公开基线独有的board_control.cpp、board_control.h、board_transport.h保留作历史参考；它们不在1.6.8实板默认构建与服务注册中，因此没有把旧RPC接口与BLE08混搭或宣称旧客户端完全兼容。App与服务器需使用匹配的BLE08/HTTPS协议；更新固件前应核对各端能力。

没有复制device_config.h、device_adb_keys.h、设备令牌/身份头、生成sdkconfig、build/bin、私有音频和其他私有资产。既有公开通用音频继续保留。测试目录的sdkconfig.h仅为静态空测试夹具，配置由编译器-D提供，不是设备运行配置。

## 与原私有镜像的明确差异

1. 硬编码的TLS服务器名、HTTP Host改为可选私有配置。普通HTTPS默认按URL核验主机名、使用证书bundle，明确保持`skip_cert_common_name_check=false`。代理覆盖只改变期望的合法身份，不跳过认证。
2. 历史ADB代理目标需要显式私有配置，拒绝空地址、选项和命令分隔字符；默认生产仍不编译ADB传输实现。
3. 原私有构建强制开启的USB维护诊断改为Kconfig默认关闭，维护者须显式开启。PCUSB INFO及带随机challenge的AUTH证明、STOP保留在门控外；普通构建不编译其他raw CLI（包括REBOOT/BOOTLOADER/OTA/WIFI/VOICE写操作），也不接受CDC DTR/RTS序列触发软件下载模式；实体BOOT恢复入口保留。日常签名BLE/HTTPS任务不依赖该诊断开关。
4. 保留已公开的通用示例、资源和清理后的存储元数据，不复制私有部署信息。

因此它不是原私有镜像的逐字节复刻，不能引用私有镜像哈希冒充本候选镜像。

## 可复用与新增验证

私有1.6.8已有ESP-IDF6.0/ESP32-S3/8MB云构建、镜像校验及14套C++和5项Python测试证据。这些可作为被同步实现的来源证据，不代表本次公开配置化候选重新通过了完整固件构建。

候选另有可独立运行的`tools/test_firmware168_host.sh`：原14套主机测试、USB证明/控制台路由及DTR/RTS门控测试、3种TLS/Host/代理配置编译运行、资源生成与默认维护关闭检查。所有测试只使用合成令牌或.example.invalid/文档地址，不依赖私有部署或设备。还使用原1.6.8 SDK环境对相关源文件做默认/维护配置的仅语法检查，不生成对象或固件镜像；这不替代完整链接或上板验收。实际手机输入、输入法候选、断网停止、投屏生命周期、OTA/回滚及电源仍需匹配环境验收。

已知限制：HID模式切换仍会重枚举USB；BLE先断开可能造成投屏会话结束。该同步没有把尚未实现的固定USB身份方案写成已修复，也没有通过保留旧任务来规避重新授权。
