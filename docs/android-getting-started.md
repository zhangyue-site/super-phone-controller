# Android 安装与使用

## 安装与更新

- 打开[官方下载页](https://d.zhangyue.site/apps/phone-controller-flash/)。截至 2026-11-18，已核对主下载 APK 为 `site.zhangyue.pcflash` **1.4.10（83）**；该包最低要求 Android 8.0（API 26）。
- 已装主包的手机使用同包名、同签名安装包覆盖更新。如果 Android 提示签名不匹配或拒绝降级，先停下核对原安装身份和版本，不要为了绕过提示而卸载 App 或清除数据。旧安装身份 `org.example.phonecontroller` 要找匹配的兼容包。
- App 的更新入口打开官方下载页，不等同于应用内静默 OTA。固件更新是另一条流程，见[发布与恢复](cloud-development-and-ota.md#发布与恢复)。
- 界面开发分支不替代正式下载。未签名或调试签名的 APK 不能当作正式版覆盖。

## 第一次连接

1. **被控手机**：接入支持数据的 USB / OTG 线和控制板。打开「被控手机」页面，检查 USB、整屏共享、任务服务和操作许可四项。按 Android 系统提示开始整屏共享；只有你能授予该许可。
2. **建立网络路径**：板端直连时，在控制板网络入口配置 Wi-Fi；使用手机中转时，根据连接页提示授权蓝牙或附近设备。共享中不代表云端在线。
3. **绑定**：在被控端选择「连接控制手机」，在另一台手机选择「控制手机」并输入页面当前的绑定码。不要公开绑定码或共享画面。已有绑定仍由原会话和服务规则决定能否恢复。
4. **下发任务**：先用「打开设置」这类低风险操作，核对目标及本次任务范围，确认后再执行。控制手机无需共享自己的屏幕。进度和结果以真实回执及核验为准。

## 连接中断或需要停止

| 看到的状态 | 怎么做 |
| --- | --- |
| USB 未连或身份待核验 | 检查支持数据的线、OTG 与目标控制板，按页面提示重查；不要改用 ADB 操作。 |
| 系统已结束共享 | 回到被控手机，由本人重新开始整屏共享。仅进入设置或切换主题不主动结束现有共享。 |
| 中转连接失败 | 保留当前任务状态，到被控端查看错误；切换中转前先停止控制并按页面指引释放现有中转。 |
| 停止请求待确认或失败 | 不把请求发出当作已停；必要时立即使用板上停止按钮。 |
| 任务回执或结果不明 | 先看进度和新画面，不重复发送旧动作。必要时重新核对目标后创建新任务。 |
