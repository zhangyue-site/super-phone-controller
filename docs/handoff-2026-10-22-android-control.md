# Android 控制入口

现有升级助手新增“手机控制”：连接控制板后，从右上角进入。输入“打开微信找到李洋”生成计划，点击确认才进入云端队列。可停止、查看结果、保存已核验技能；现阶段专项执行仅微信联系人搜索，停留结果，不发消息。

控制页使用独立五分钟 BLE 持有证明授权，票据仅驻内存；APK 没有设备长期密钥或龙虾桥接令牌。固件下载、屏幕共享、命令三种授权不通用。新授权撤销旧 App 票据和未终结任务；确认必须带明确计划编号。原微信/Telegram 入口和 App 共用 RemoteControl 队列，设备级停止覆盖各入口。

画面仍由系统确认的 MediaProjection 提供；HID 点击/移动/拖动和中文 ADB 输入沿用既有执行器。App 不启用无障碍、ADB 截图、ADB 点击或启动应用。手机须解锁、整屏共享，控制板须新固件及本地 HID 许可。

验证：根目录 135 项 Python 测试通过。新增四个真实 HTTP 模拟用例覆盖 App 授权、预览不执行、明确确认、板子领取、合成画面、HID 回执、中文输入、结果核验、技能保存、停止、过期/撤销、跨票据和跨范围拒绝。不是实机成功。

云端部署备份 `/var/lib/phone-controller/backups/app-control-20261022-145632`，只补入 App 路由和相关模块，保留其他语音改动。公网未授权命令返回403。正式 Flutter CI 校验分析、客户端授权协议及页面停止响应顺序；最终构建/发布证据见补充记录。
