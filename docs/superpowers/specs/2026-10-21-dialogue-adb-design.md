# 屏幕语音对话与本地 ADB 执行

用户已要求接入聊天回答、手机执行、结果语音播报，并重点验证 ADB；在106分析现有服务，保持手机不安装App、不依赖Mac、USB本地网络和WiFi关闭的原要求。

采用106对话任务与板端执行分离：语音上传带明确 dialogue 标记后创建异步任务；板端轮询本设备/启动会话/语音序号对应的下一项动作，HTTP关闭后才交给ADB worker执行，回传真实结果。避免同一ADB连接既承载HTTPS又等待shell产生死锁。旧语音客户端仍仅ASR，不自动获得执行行为。

106读取现有模型配置，维护有界短期会话记忆。模型只能选择reply/observe/home/back/open_settings/tap/scroll/done/stop。操作必须基于本轮新读的UI节点；tap/scroll发送真实节点身份和bounds，板端操作前再次读取并比对完整观察，变动即拒绝。完成必须再次观察，回复区分submitted与verified，完成判断基于最新观察。无原始任意shell、无猜测坐标、锁屏不操作。只复用配置和执行模式，不调用旧offline中继。

ADB单worker串行负责握手、固定TLS代理、固定只读观察和有界操作。每请求带授权ticket，停止撤销ticket，正在执行/排队请求都失效；发送未知结果不重放。读观察含前台、锁屏、屏幕尺寸、UI XML；截断、命令失败或变化均失败关闭。连接错误单独报告未获地址/端口拒绝/超时/授权失败/只读失败/丢失；不假称重启后自动开启5555。

结果由106的在线TTS转16kHz单声道PCM，最大30秒，板端下载后单worker播报，与收音串行；静音跳过播放，不改变执行结果。语音页保持大块停止区域，处理/执行/播放期间均能中止。离页停止整个回合。失败不自动续听执行；成功播报后继续下一轮，最多12轮。无声退出。

任务绑定device+session+sequence，命令ID只交付一次；重复poll返回等待而不是重放，丢失ACK使任务失败。停止/心跳超时取消任务，旧回合ACK不被新任务接受。服务器保留每设备至多一个任务、24条内存对话和短期音频，无音频长期存储。普通聊天不访问手机。外发消息、支付、删除等不可逆动作不纳入本次默认自动操作。

验证：ADB协议模拟器、节点验证/锁屏/陈旧观察/重复投递/停止跨代测试、HTTP隔离与流式语音测试；106真实模型+TTS测试；固件编译。实物只有目标小米及板子被识别在线后才做只读、打开设置、回首页和停止测试；offline不能冒充通过。

硬预算：单回合180秒、最多8次模型决策、最多6个输入动作，每次ADB命令12秒；任务15秒未poll失效。节点操作仅导航（打开/进入/查看/返回/列表/详情/账单/设置/菜单/分类/首页等标签），拼接祖先/子节点标签拒绝发送、支付、删除、提交、授权、登录、修改、保存及英文同义词。只读观察跳过password节点。手机执行器不接收任意文本输入/包名/shell。open_settings只允许固定系统设置Intent；home只允许固定HOME。模型done必须有新观察原文evidence，设置/home另外校验前台包/launcher类别；证据不匹配仅返回未验证。

打开应用使用typed launch：固定命令查询手机真实MAIN/LAUNCHER Activity列表，最多128项，模型只选择当前列表项，板端输入前重读并核对，固定启动Intent和字符/参数约束。不会因为桌面节点可点击就把小组件当App。完成要求目标包在前台，后续tap/scroll保持目标包约束。
