# 板载语音输入

用户要求先完成软件，保持无手机App、无Mac运行依赖、默认WiFi/HID/蓝牙关闭。复用106云端ASR，暂不将识别文字冒充手机动作执行。

NCM五页顺序：额度、交互、控制确认、网络、语音。语音页按住小太阳250ms进入准备，麦克风启动去除1秒瞬态后录音，继续按住至少0.4秒，松开上传，最长10秒。短按仍翻页，其他普通页长按停止；控制确认页授权逻辑保持。界面逐步提示准备、录音、上传、识别结果或失败，底部按页面显示实际操作。

ADC按次打开关闭，IDF5.5 RX enable清空队列，录音前后DMA样本不用于上传；缓冲320KB PSRAM。音频仅经过TLS上传106，服务器鉴权后限制长度、拒绝静音，临时WAV0600、识别结束删除。使用已有/opt/cardputer-phone/asr.py调用云服务，不在板子放云端密钥，不自动执行识别文字。

停止携带启动随机会话与递增录音序号。服务器记录取消截止序号，拒绝停止先到、旧上传后到的竞态；原有服务generation同时拒绝识别过程中停止后的结果。每设备会话历史最多16项。重启权限全部关闭。

验收：音频验证与HTTP取消测试，NCM/CDC构建，实板MIC TEST仅打印RMS/peak不上传、记录后关闭，重启默认值，106真实合成语音ASR。实际手机USB网络与按住说话仍需直连接线验收，手机动作执行/屏幕采集未完成。
