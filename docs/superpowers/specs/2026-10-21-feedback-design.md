# 点击提示音与实机准备

用户已确认：有效点击轻响；开始收音两声上扬；停止立即撤销并短低音；成功、失败区分。提示音与语音共用持久化音量（0–100、每档20）和静音，静音不影响收音或屏幕。点击反馈只确认接收，不代表手机已执行。

音频由现有 voice worker 串行播放，禁止并发操作 codec。短音采用离线合成、淡入淡出；开始提示完成后才打开麦克风。停止撤销当前播放和任务后排入停止音。录音期间不播放点击音；普通点击不在忙碌任务结束后补播。成功仅在 dialogue 返回成功后反馈。

ADB 通用恢复采用板端 USB Host、手机 USB Device 标准 ADB，不依赖手机 App、Wi-Fi 或 TCP5555。现板 CC 为受电模式，主机模式必须配合独立受保护的5V供电与正确USB角色，不能仅刷固件。首次 USB 调试授权以及部分设备重启后的首次解锁仍需机主操作。当前板端网络固件验证与手机重启恢复验收分别记录。

验证：可移植音调/优先级测试；固件编译；备份后板端启动、音量/静音保存、收音互斥和停止检查；有授权测试手机及主机接口后，再做冷启动、拔插、重启和锁屏恢复。未完成项目明确标记待测。
