# 小米17U USB联网与控制验证

用户要求：不装App，运行时手机加板子，脱离Mac；已接受在手机手动开启以太网共享。每次重启默认关闭HID/Wi-Fi/蓝牙，屏幕实体确认后才开启输入。

当前真机证据：手机USB网络共享为2717:ff88 RNDIS复合设备；GET_PROTOCOL返回AOA2。参考scrcpy的ID2及发送顺序后注册、描述符、相对鼠标移动、注销均成功，用户已确认看到指针。第一轮自定义ID注册返回STALL，原因尚未确认，不宣称所有请求兼容。Mac仅用来检测协议，不构成最终运行方案。

硬件：板子USB-C有5.1k下拉，充电/3.3V供电电路未提供5V主机输出；电池不能直接等同USB主机供电。因此先验证板子作为NCM虚拟网卡、手机作为USB主机并通过以太网共享提供DHCP及互联网的方向。该方向可同时暴露HID，但默认无HID。

实现：保留稳定CDC固件；独立NCM构建配置增加网络控制/数据接口及DHCP客户端，默认不启用Wi-Fi。串口STATUS/LOGS与本地网络页展示USB/IP/106进度。仅在拿到IP后请求106已有TLS认证接口。物理断开USB撤销输入授权，内部有意重枚举与物理断开区分。若手机内核不识别NCM或没有以太网共享入口，记录实测结果，不把Mac联网当作成功。

先通过识别、DHCP、106通信，再验证屏幕确认HID、手机输入、停止与重启关闭；未通过前不接入自动执行任意操作。

NCM测试构建已刷板，Mac检测到PID4041、CDC+NCM接口、无HID，状态net=2有RX/TX，等待用户直接接手机测试。稳定软件BOOTLOADER返回原生下载口已通过，刷写无需重新拆电池。
