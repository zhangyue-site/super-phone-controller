# AMOLED maintenance, version visibility and reinstall
User-approved design: the settings page permanently displays actual running firmware version. A Power entry opens a focused menu for Restart or Power off, each with confirmation and Cancel. Returning cancels a pending choice. Successful power-off is driven by PMIC, not a black screen.
The firmware accepts valid image-bound authorization for newer, same and older valid AMOLED releases; project, hardware family, slot bounds, full digest, nonce freshness and cancellation remain required. The phone displays current → target and requires explicit user confirmation before reinstall or downgrade. Older firmware may retain stricter policy and must not be represented as supporting reinstall.
Before software power action revoke HID ownership and cancel an active OTA write. Wait for actual cancellation/abort completion before restart or PMIC shutdown. During OTA commit reject ordinary menu power actions and explain why. Never force power loss to work around commit safety. Hardware long-press behavior is a separate PMIC recovery route, with measured USB and battery behavior still required.
Acceptance: host policy tests for reinstall, downgrade, invalid versions, STOP, cancellation and commit guard; real cloud firmware build; actual running version and screen snapshot; reboot and power-off reported separately and only after user-authorized physical tests. Authentication failure remains unresolved until a concrete rejected stage is observed; expose safe stage/reason diagnostics rather than remove identity or image checks.

Review resolutions: settings uses the running app descriptor. A power reservation atomically cancels before COMMIT and prevents new BEGIN; only the writer reports quiescence after abort returned. A cancellation timeout keeps the device running. New INFO exposes manual-confirmed-any capability and actual runningSlot; new boot, target ELF, imageState and slot evidence distinguish same-version rewrite. Legacy downgrade capability and missing evidence are reported explicitly. PMIC acceptance is not treated as proof of rail shutdown; USB and battery tests remain separate.
