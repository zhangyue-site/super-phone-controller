# 可选无障碍辅助定位

Android 原生 AccessibilityService 提供有界的可见文字与控件位置，随用户授权的屏幕共享帧上传。它仅辅助观察与精确定位；操作仍经板端 HID、图像围栏及动作后的新帧核验执行，不引入无障碍手势执行器或新的模型端点。

服务默认关闭，由用户在系统设置中开启；没有有效共享时不采集。密码及不可见节点不发送。读取限制节点数、深度、遍历时间、文字长度和总负载；页面变化、尺寸变化、过期或解绑时放弃节点，保留原图像路径。

服务器将辅助信息绑定到鉴权能力、任务、图像 SHA、序号与屏障。任务终止或共享撤销后不可复用。界面文字属于不可信环境数据，不能作为执行指令；节点缺失不能作为财务记录不存在的证据。

无障碍事件与 MediaProjection 不提供原子快照，因此节点只是有时限、与帧关联的辅助观察。实现检查图像时间戳不早于最近事件、采样代次一致、服务仍绑定；监听文本、选择、焦点、点击和窗口事件，不以事件合并延迟掩盖页面变化。原图像围栏和结果核验保持生效。

共享、中转与辅助定位状态分别展示，可关闭辅助并继续图像链路。实现、构建、安装与真实业务完成须分别验收。本实现使用 Android 平台接口，不包含第三方代理项目源码。
