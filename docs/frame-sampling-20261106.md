# 可选静态画面取样

静态页面可能长时间没有新的 ImageReader 回调。设置中的实验取样选项默认关闭，仅在系统投屏、同一物理 USB 会话和云端授权有效，且活动任务需要新画面时启用。它不延长控制许可，也不自动确认系统投屏。

当前实现复用同一个 VirtualDisplay，绑定新的同尺寸、非空 ImageReader Surface。旧 reader 保留到新 reader 产生尺寸正确且时间戳递增的真实 Image 后才关闭。最多同时持有两个 reader；不解绑到 null、不改变尺寸、不再次创建 VirtualDisplay，也不复制旧位图伪装新帧。

取样有频率、上传忙碌和源帧年龄限制。物理恢复独立于云端屏障；四秒内未获得真实新图就停止共享并记录错误。STOP、拔线、授权撤销或几何变化会阻止继续取样。生命周期锁与 reader 身份检查拒绝过期回调。

设置写入成功后才更新界面，失败保留原状态。验证需覆盖静态页、任务切换、HID 后新帧、关闭取样及会话撤销；单次取图成功不能替代连续运行验收。
