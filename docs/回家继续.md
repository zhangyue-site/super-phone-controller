## 诊断方式

在仓库根目录：

    python3 tools/board_console.py status
    python3 tools/board_console.py storage
    python3 tools/board_console.py logs
    python3 tools/board_console.py sdlogs > /tmp/phone-diagnostics.txt
    python3 tools/analyze_tf_logs.py /tmp/phone-diagnostics.txt

卡上专用目录 /SPASSIST/：
- DIAG.LOG / DIAG.OLD：循环日志，每份不超过64 KiB。
- CLOUD.MD / CLOUD.JSN：云端Skill参考快照和SHA/来源元数据；不是ESP32可执行脚本。

ADB诊断码：1无对端地址，2端口拒绝，3连接超时，4套接字失败，5授权/握手失败，6固定只读命令失败，7连接丢失。

首次打包Skill可先从已授权服务器取回原文本到ignored的private-backups，再执行：

    python3 tools/prepare_skill_cache.py private-backups/cloud-phone-skill.md

SHA只校验完整性，不代表签名信任。TF上的Skill不会自动获取命令执行权。未同步密钥或录音到GitHub。
