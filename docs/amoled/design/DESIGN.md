# 手机控制助手 · AMOLED 2.16 插件化设计规范 V0.3

> 首版设计稿。金额、日期、笔数和连接状态都是示例；没有刷写设备，也不表示固件已实现。导入的示例文件不等于正式可执行插件包。

## 架构修正

**自动记账属于导入插件，不是固件内置功能。** 核心首页只有语音任务、插件、手动控制、设置。默认插件列表为空；导入后再配置和运行。插件可更新与移除，业务变更不应要求重新刷固件。

- 通用核心：设备连接、共享状态、语音、触摸、手动HID、任务暂停/回执、通用视图渲染。
- 插件业务：用途、参数、业务流程与页面、业务结果核验。自动记账的消费规则、金额核对、阿柴页面都归插件。
- 106与手机助手：规划为导入、保存、同步和承载插件流程；设备只展示和执行已下发的通用动作。

当前只完成设计与原型。浏览器可实际选择JSON描述文件，演示导入/去重/更新/移除；没有实现手机端导入API、106正式插件加载器或固件插件运行时。

## 设备与设计范围

面向用户已确认的 **ESP32-S3-Touch-AMOLED-2.16**。按厂家公布的 **480×480** 设计，显示驱动为 CO5300、触摸为 CST9220。依据：[Waveshare 官方资料](https://docs.waveshare.com/ESP32-S3-Touch-AMOLED-2.16)。容量、引脚和具体硬件版本仍需固件适配时核对。

`overview.png` 是八状态总览；`prototype.html` 是无需联网的可点演示；`screens/` 是十六张原生 480×480 屏幕图；`native-layout.json` 导出交互演示中各按钮的真实布局坐标，可作为后续控件实现的起点。

## 信息层级

1. 顶部：USB、屏幕共享、云端三个状态分别呈现。
2. 中央：当前动作和金额，优先于设备细节。
3. 下部：暂停、返回等本页操作；首页提供四个主要入口。
4. 说明：仅在必要时解释下一步。界面不用“严格幂等”“审计”等实现术语。

| 颜色 | 值 | 用途 |
| --- | --- | --- |
| 屏幕背景 | `#000000` | AMOLED主画面 |
| 控件底色 | `#1C1C1C` | 普通操作与分组 |
| 主要文字 | `#F5F5F5` | 当前状态、金额 |

## 页面

新增插件中心空状态、已导入列表、手机导入等待、插件详情、参数设置与插件管理页。下表中的金额/账单页面属于自动记账插件，不是通用固件页面。

| 页面 | 主要内容 | 操作 |
| --- | --- | --- |
| 首页 | 准备就绪，三层连接状态 | 语音、插件、手控、设置 |
| 插件运行 | 由当前插件提供状态、字段与步骤 | 通用暂停 |
| 已添加 | 已记过、自动跳过、正在返回 | 自动流转，不要求确认 |
| 金额纠错 | 列表金额与识别金额并排 | 自动取消/修正/再核对；可暂停 |
| 自动重连 | USB与共享保持、云端恢复中 | 结束本次任务 |
| 保存待核验 | 已提交、核对结果、不会再次保存 | 暂停；只核验旧提交 |
| 范围完成 | 已记、跳过、待核数量与日期边界 | 返回首页 |
| 手动控制 | 四向滑动、点按、手机返回与主页 | 暂停；退出回控制器首页 |
| 语音二级页 | 按住说话、松开查看识别结果 | 退出 |
| 设置二级页 | 声音与亮度、网络、固件信息 | 明确断开共享 |

## 交付边界

设计总览与可点演示属于同一方向的概念稿，部分间距和文字在演示中做了可读性调整；不是现有固件的逐像素截图。尚未实现 LVGL 控件、LCD驱动、触摸驱动或任何真实控制。触控手感、中文字形、圆角裁切、旋转方向、亮度与刷新表现都要在板上验收。
