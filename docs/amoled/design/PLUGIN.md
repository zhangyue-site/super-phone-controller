# 插件模型 · 设计提案

> 仅用于此版设计原型。当前JSON描述格式不是已发布的手机/固件插件标准；正式包格式及导入接口尚待实现。

## 职责划分

通用固件提供连接、共享状态、语音、触摸、HID分发、回执和通用视图。自动记账等业务通过独立插件导入，插件提供名称、版本、用途、参数、流程与视图。

正式执行优先复用106上的流程与识别服务。设备不承担Python/OCR模型，不应为每增加一项业务重新编译固件。插件自身也不携带用户设备密钥。

## 原型示例

`plugins/auto-bookkeeping.plugin.json` 包含：

| 字段 | 含义 |
| --- | --- |
| format / apiVersion | 描述文件类型与接口版本 |
| id / name / version | 稳定标识、显示名称和版本 |
| description | 用途说明 |
| runner | 计划中的106流程入口；原型不会调用它 |
| parameters | 插件参数，如处理到的日期 |
| ui | 示例运行、跳过、纠错、待核验与完成数据 |

原型只读入描述数据并展示；不执行文件中的代码，不调用真实流程。自动记账示例和另一种通用插件都已验证可导入、显示及移除。

## 版本与生命周期

导入 → 已安装 → 配置 → 运行/暂停 → 完成或结束。已安装插件可更新或移除；同ID同版本只打开现有条目，新版本保留参数，低版本不覆盖。运行时先结束任务再更新或移除。

正式实现还需完成插件包资源、106注册/加载、手机导入入口、同步协议、持久化、运行事件、版本兼容及实际设备验收。本轮没有实现这些能力。
