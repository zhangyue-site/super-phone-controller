# 手机控制助手 · 插件化交互 V0.3

## 核心首页

四个入口：**语音任务 / 插件 / 手动控制 / 设置**。自动记账不是默认按钮，也不作为固件固定业务。

## 插件导入流程

```text
插件中心（默认空）
  → 从手机导入
  → 手机助手选择插件包并完成导入
  → 同步名称、版本、用途和页面到设备
  → 在设备打开插件详情
  → 设置参数
  → 开始运行
```

导入与运行分开。未导入时不显示可运行的自动记账，导入完成不会自行开始任务。

正式导入会通过手机助手/106完成，控制器显示同步状态。本轮原型用浏览器文件选择器模拟手机导入，不表示这些API已经存在。

## 已导入插件

- 插件列表：名称、版本、已导入/运行状态；点击进入详情。
- 插件详情：用途、参数、开始运行。
- 参数设置：由插件声明；示例记账插件有截止日期与消费支出范围。
- 插件管理：查看详情、导入新版本、移除。
- 更新：同ID新版本替换旧版本，保留用户参数；同版本去重，不建立重复条目。
- 运行中的插件：先结束任务再更新或移除，避免当前流程突然失去配置。
- 移除插件不等于刷写/卸载固件；正式实现应保留已执行任务的核验记录。

## 示例：自动记账插件内部流程

```text
消费账单 → 点开 → 等阿柴识别
                 ├─ 金额不同：取消 → 修正 → 再核对
                 ├─ 金额相同且已添加：跳过 → 返回 → 下一笔
                 └─ 金额相同且未添加：保存一次 → 核对结果 → 返回
保存结果待核验：只读核对旧提交，不再次保存
```

分类沿用阿柴，不额外取交易号。日期范围由插件参数决定，9月10日只是本次示例。上述规则和业务页面都归插件，不固化到通用固件。

## 暂停与连接

暂停任务保持共享与中转；结束本次任务返回插件列表且保留连接。网络短断由通用核心恢复，不重复发送旧动作。拔线或在设置明确选择断开共享时结束控制。

插件显示“完成”前须核对结果，待核验记录不得计入已记数量。这些是目标交互语义，正式运行仍需后端与固件联调。

## 如何体验本原型

1. 打开prototype.html，点击设备首页的“插件”，初始应为空。
2. 在浏览器右侧点“导入示例插件”，或下载示例JSON后用“选择插件文件”导入。
3. 打开插件详情，设置日期并开始运行。
4. 查看插件运行、跳过、纠错、待核验和完成页面。
5. 结束任务后进入插件管理，可移除插件；列表将再次为空。

演示列表仅保存在本次页面会话中，刷新会重置。正式实现应持久保存已导入插件与用户配置。示例文件不包含真实账单、凭据或设备身份。
