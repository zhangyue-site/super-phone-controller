# Android 界面与验收

Material 3 界面候选基于 Android 1.4.10（83）构建提交 `418f15c`。沿用 Flutter 自带组件和项目浅色、深色、跟随系统主题，不增加 UI 依赖，不更改权限、接口、任务或设备状态机。

| 页面 | 重点 |
| --- | --- |
| 首页 | 首屏说明双手机分工；小屏角色入口纵排，宽屏且字号适合时并排；共享仍有效时先显示返回被控端的快捷入口。 |
| 任务 | 待确认、执行、结果和停止未确认继续使用原始状态。建议任务仅填入输入框，不会开始执行；真正确认仍走原按钮。 |
| 被控连接 | 汇总控制板与 USB、整屏共享、任务服务、操作许可；失败留在对应页面，不用短暂通知取代。 |
| 设置 | 按外观、连接与辅助、升级与恢复、控制板功能分组。主题使用原设置入口，不重新绑定或结束共享。 |
| 提示与确认弹窗 | 内容按小标题分段。解绑、换码和升级先说明会影响什么，再给对应操作按钮；取消仍走原退出路径。下载失败留在更新弹窗内，可重试或关闭。 |
| Android 悬浮状态条 | 展开后分行显示电量、共享、本机中转和最近回执。不把「本机未中转」误写成「控制板未连接」；关闭浮窗不停止控制或共享。 |

任务、连接及从两者进入的设置页仍保留底部停止入口。按钮不弹出新的确认框；原有处理中、失败与重试条件继续有效。没有添加装饰动画；输入框保留清晰的键盘焦点边框。

## 检查项

按 [App 配置与测试](app-configuration.md) 准备固定模型后，先运行相关 Widget 测试，再跑完整回归：

```sh
cd app
flutter test --dart-define=CONTROLLER_BASE_URL=https://controller.test \
  test/role_home_test.dart test/theme_modes_test.dart test/theme_widgets_test.dart \
  test/control_screen_test.dart test/usb_widget_test.dart test/widget_test.dart
```

实际设备验收时检查浅/深色、窄屏、大字号、键盘与 TalkBack，确认长状态可读、滚动后停止仍可触达。分别演练正常配对、共享失败、网络断开、停止待确认与从设置返回；过期或结果未知的任务不可重放。Widget 与静态检查不代替真机、双机任务、固件或分发验收。
