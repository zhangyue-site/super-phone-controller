# UI 决策模型训练管线（ui-model）

手机 UI 自动化的神经决策模型：输入任务文本 + 屏幕OCR行，输出标准动作 JSON（click/scroll/input/back/done）。

## 架构

```
真实审计数据(916帧) ──┐
                      ├─→ 语料抽取器 ──→ 仿真器合成真值语料 ──→ QLoRA SFT ──→ 评测 ──→ 闭环仿真计分
虚拟账单环境(无限出题) ─┘
```

- **接口通用**：任意 task 文本 + 任意屏幕 OCR 行(text/bounds) → `{"thought","action":{"type","bounds"}}`，坐标系 588×1280
- **技能靠数据**：换领域只需喂该领域语料，代码零改动

## 快速开始

```bash
# 1. 抽取真实语料（从审计目录）
python3 make_sft_ui_v4.py

# 2. 生成合成真值语料（回合式，带history+无效恢复样本）
python3 gen_sft_syn_v2.py

# 3. 合并训练（Qwen3-0.6B + QLoRA r=32, seq 1280）
cat sft_ui_v4b.jsonl sft_ui_syn2.jsonl > sft_ui_r6.jsonl
python3 train_ui_lora.py   # 改 DATA/OUT 路径

# 4. 评测（静态样本 type/定位）
python3 eval_ui.py

# 5. 闭环仿真（虚拟账单环境，3回合×10单）
python3 sim_env.py

# 6. 仿真保真度校验（真实审计动作 vs 仿真规则）
python3 sim_fidelity.py
```

## 结果（2026-11-15）

| 轮次 | 语料 | 静态评测 | 闭环仿真(30单) | 无效动作/120 |
|---|---|---|---|---|
| R1 真实语料 1226 条 | 审计HID坐标换算 | 3/6 · 1/6 | 0 | 119 |
| R2 +决策语境thought | 1321 | 3/6 · 0/6 | 0 | 119 |
| R3 +合成真值 | 3921 | 3/6 · 1/6 | 2 | 118 |
| R4 纯合成 | 2600 | 2/6 · 0/6 | 4 | 116 |
| R5 scroll bounds修复 | 3921 | 3/6 · 1/6 | **13 (43%)** | 111 |
| R6 回合式history+无效恢复样本 | 4321 | 待测 | 待测 | 待测 |

**关键教训**（踩过的坑，别再踩）：
1. 训练前必查 token 长度分布 vs max_seq_length——曾 100% 样本被截断，loss 0.085 但模型全是残缺输出
2. 模型输出是多行美化 JSON，推理 max_new_tokens 必须 ≥300
3. 真实拖拽事件无终点坐标（单点拖拽），scroll 样本 bounds 必须修正为整屏列表区，不能退化为点
4. 合成语料必须带 history（回合式出题），单步样本学不会状态推进
5. 陌生画面会触发格式崩坏（bounds 输出成字典），合成多样画面是疫苗
